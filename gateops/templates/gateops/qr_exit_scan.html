How it works

  1. The QR code can be a Pass code (printed on the visitor pass) or a GateEvent UUID.
  2. The system resolves the code to exactly one ENTERED event in {{ scope_society_name }}.
  3. The exit transition is delegated to GateEventLifecycleService.record_exit() — the same state machine used by the manual exit button.
  4. The host is notified of the exit automatically (non-blocking).
If the code is invalid or the visitor is not currently inside, an error message will be displayed.
